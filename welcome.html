ติดตั้ง Auto Language Fixer แล้ว

แก้พิมพ์ผิดภาษาไทย-อังกฤษด้วยคีย์ลัดเดียว

เริ่มใช้งาน

  1. คลิกในช่องข้อความ แล้วพิมพ์ตามปกติ
  2. ถ้าพิมพ์ผิดภาษา กด Ctrl + Shift + Space (Mac: Cmd + Shift + Space)
  3. อยากแปลงทั้งช่อง กด Ctrl + Shift + Y หรือไฮไลต์ข้อความก่อนกดคีย์ลัดเพื่อแปลงเฉพาะส่วนนั้น
  4. กดซ้ำเพื่อสลับกลับได้ หรือคลิกขวาในช่องข้อความแล้วเลือก "แปลงภาษา"

ตัวอย่าง

l;ylfu→สวัสดี
ไนพก→word
hELLO→Hello

เคล็ดลับ

  1. กดไอคอนรูปจิ๊กซอว์บนแถบเครื่องมือของ Chrome แล้วปักหมุด Auto Language Fixer ไว้ จะเปิดหน้าตั้งค่าได้สะดวก
  2. ในหน้าตั้งค่าเลือกได้ว่าถ้าไม่ได้ไฮไลต์ จะแปลงคำล่าสุด ทั้งบรรทัด หรือทั้งช่อง และเปลี่ยนคีย์ลัดได้
  3. อยากลองทันที เปิด google.com แล้วพิมพ์ผิดภาษาในช่องค้นหา

ใช้ไม่ได้ในหน้า New Tab, address bar, หน้า chrome:// และตัวดู PDF (Chrome ไม่อนุญาตให้ extension เข้าถึง) · ไม่เก็บและไม่ส่งข้อมูลที่คุณพิมพ์ออกนอกเครื่อง · GitHub
